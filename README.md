# Embroidery Clothing E-Commerce Website

Full Stack E-Commerce Website built using:

* Java
* JSP
* Servlets
* MySQL
* HTML
* CSS

## Features

* User Registration \& Login
* Shopping Cart
* Product Catalog
* Admin Dashboard
* Product Management
* Order Management
* wishlist
* Add to Cart
* order tracking
